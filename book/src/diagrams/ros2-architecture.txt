## Components Explained

### Nodes
- The basic unit of computation in ROS 2
- Each node performs a specific task
- Nodes communicate with each other through topics, services, and actions

### DDS/RMW Layer
- Data Distribution Service / Repository & Middleware
- Handles the underlying message passing
- Provides QoS (Quality of Service) policies
- Supports multiple implementations (Fast DDS, Cyclone DDS, etc.)

### Client Libraries
- rclcpp (C++)
- rclpy (Python)
- rcl (C)
- Provide the ROS 2 API for developers

### Communication Patterns
1. **Topics** - Publish/subscribe pattern for asynchronous communication
2. **Services** - Request/response pattern for synchronous communication
3. **Actions** - Goal-based pattern for long-running tasks with feedback
